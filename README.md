## ⚡ Automated Installation
Run the following command on your server to install WireNest Panel automatically:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/wirenest/wirenest-panel/master/install.sh)
```

## 🔥 Detailed Features
### 🏢 Panel Maker System
- **Automated Provisioning:** Create dedicated sub-panels and accounts seamlessly.
- **PasarGuard Integration:** Native and secure communication with PasarGuard API.
- **Multi-Node Support:** Manage proxy servers and nodes from one central bot.

### 💰 Financial & Sales Engine
- **Instant Wallet:** Automated top-up system for users.
- **Receipt Verification:** Automated review and approval queue for payment slips.
- **Discounts & Gifts:** Built-in support for discount codes and top-up gift cards.

### 🤖 Automation & Delivery
- **Instant Config Delivery:** Seamless purchase flow resulting in instant config delivery.
- **Free Trial Service:** Offer time-limited trials with automated expiration tracking.

### 🛠 Admin & Security
- **Smart Dashboard:** Real-time stats, mass broadcast system, and ticket support.
- **Robust Security:** AES-based encryption for sensitive data.
- **Maintenance:** Emergency power switch for quick bot management.

## 🛠 Management CLI
After installation, you can manage the bot using:
- `wirenest-panel update` — Update from GitHub
- `wirenest-panel status` — Check bot health
- `wirenest-panel restart` — Restart the service

## 📂 Project Structure
- `pesarguard/` — Core engine (logic, database, handlers).
- `run.py` — Main entry point.
- `requirements.txt` — Python dependencies.
