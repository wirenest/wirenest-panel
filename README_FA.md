# 🤖 WireNest | بازارساز پنل پاسارگاد و ربات فروش 🚀

### یک ربات تلگرامی پایتون برای ساخت پنل‌های پاسارگاد، مدیریت سرویس‌های پروکسی و اتوماسیون فروش

[![Python Version](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://python.org/)
[![Platform](https://img.shields.io/badge/Platform-Debian%20%7C%20Ubuntu-lightgrey.svg)](#-requirements)

[English 🇺🇸](README.md)

WireNest به شما اجازه می‌دهد پنل‌های پاسارگاد را کاملاً از طریق تلگرام بفروشید و مدیریت کنید. مشتریان پلن‌ها را مشاهده می‌کنند، کیف پول خود را شارژ می‌کنند، سرویس می‌خرند و اطلاعات پنل را بلافاصله دریافت می‌کنند، در حالی که شما همه چیز را از پنل مدیریت داخل ربات کنترل می‌کنید. رابط کاربری ربات کاملاً فارسی است.

## ✅ نیازمندی‌ها

| مورد | نیازمندی |
|---|---|
| سیستم عامل | Debian 12+ یا Ubuntu 22.04+ (نیاز به `apt` و `systemd`) |
| دسترسی | `root` / `sudo` |
| پایتون | 3.10 یا بالاتر (نصب‌کننده این را برای شما تنظیم می‌کند) |
| تلگرام | توکن ربات از [@BotFather](https://t.me/BotFather) و آیدی عددی تلگرام شما (از [@userinfobot](https://t.me/userinfobot)) |
| پنل | حداقل یک پنل پاسارگاد در دسترس با اکانت ادمین |

## ⚡ نصب

این دستور را روی سرور خود اجرا کنید:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/wirenest/wirenest-panel/master/install.sh)"
```

نصب‌کننده از شما **توکن ربات** و **آیدی تلگرام ادمین** را می‌پرسد، توکن را اعتبارسنجی می‌کند و سپس:

1. پیش‌نیازها را نصب می‌کند (Python ≥ 3.10, git, curl)،
2. ربات را در `/opt/wirenest-panel` دانلود می‌کند،
3. یک محیط مجازی (Virtual Environment) ساخته و کتابخانه‌ها را نصب می‌کند،
4. سرویس `systemd` با نام `wirenest` را ساخته و اجرا می‌کند،
5. دستور مدیریت `wirenest-panel` را نصب می‌کند.

### نصب غیرتعاملی

```bash
BOT_TOKEN="123456:ABC-your-token" ADMIN_ID="123456789" sudo -E bash -c "$(curl -fsSL https://raw.githubusercontent.com/wirenest/wirenest-panel/master/install.sh)"
```

## 🚀 اولین اجرا

1. ربات خود را در تلگرام باز کرده و `/start` بفرستید. اکانتی که آیدی آن را به نصب‌کننده دادید، دکمه **👨‍💼 پنل مدیریت** را دریافت می‌کند.
2. در **📦 مدیریت پنل**، پنل‌های پاسارگاد خود را اضافه کرده و پلن‌های فروش (حجم و قیمت) را تعریف کنید.
3. در **⚙️ تنظیمات**، شماره کارت/صاحب حساب، درگاه‌های پرداخت و اطلاعات پشتیبانی را تنظیم کنید.
4. (اختیاری) در **📚 مدیریت راهنما**، آموزش‌های اتصال، قوانین، سوالات متداول و کدهای تخفیف/هدیه را اضافه کنید.

## 🔥 ویژگی‌ها

### 👤 برای مشتریان
- **🔐 خرید اشتراک:** انتخاب پلن، مشاهده فاکتور و دریافت فوری نام کاربری و رمز عبور پنل.
- **🏦 کیف پول:** شارژ از طریق کارت‌به‌کارت، تتر، زرین‌پال یا آقای‌پرداخت؛ تایید رسید توسط ادمین.
- **🏷 کدهای تخفیف:** اعمال کد تخفیف در صفحه فاکتور، حتی قبل از شارژ.
- **🛍 سرویس‌های من:** مشاهده سرویس‌ها، تغییر رمز عبور و خرید حجم اضافه.
- **🧪 سرویس تست رایگان:** اکانت‌های زمان‌دار که پس از انقضا خودکار حذف می‌شوند.
- **📡 راهنمای اتصال، 📋 قوانین، ❓ سوالات متداول و ☎️ پشتیبانی.**

### 🛠 برای ادمین‌ها
- **📊 آمار:** گزارش فروش و نمای کلی سیستم.
- **📦 مدیریت پنل:** اتصال چند پنل و مدیریت پلن‌ها.
- **👥 مدیریت کاربران:** مشاهده کارت کاربران، موجودی و سرویس‌ها.
- **🧾 صف رسیدها:** تایید، رد یا تایید با مبلغ اصلاح شده.
- **🏷 کدهای تخفیف و هدیه:** درصدی یا مبلغ ثابت، محدودیت استفاده و انقضا.

## 🛠 مدیریت با CLI

پس از نصب، از این دستورات استفاده کنید:

| دستور | توضیحات |
|---|---|
| `wirenest-panel status` | وضعیت سرویس |
| `wirenest-panel logs [lines]` | مشاهده لاگ‌ها |
| `wirenest-panel restart` | ریستارت ربات |
| `wirenest-panel update` | دریافت آخرین نسخه از گیت‌هاب |
