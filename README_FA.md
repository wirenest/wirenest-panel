# 🤖 ربات هوشمند WireNest | مدیریت پنل PasarGuard 🚀
### پیشرفته‌ترین ربات پایتون برای مدیریت پنل، فروش خودکار و مدیریت پروکسی

## ⚡ نصب و راه‌اندازی

۱. دریافت پروژه:
   ```bash
   git clone https://github.com/wirenest/wirenest-panel.git
   cd wirenest-panel
   ```

۲. نصب پیش‌نیازها:
   ```bash
   pip install -r requirements.txt
   ```

۳. اجرای ربات:
   ```bash
   python run.py
   ```

## 📂 ساختار پروژه
- **`pesarguard/`**: هسته اصلی شامل دیتابیس، تنظیمات و هندلرهای ادمین و کاربر.
- **`run.py`**: فایل اصلی برای اجرای ربات.
- **`requirements.txt`**: لیست کتابخانه‌های مورد نیاز (مثل python-telegram-bot).
