# 🤖 ربات هوشمند WireNest | مدیریت پنل PasarGuard 🚀
### پیشرفته‌ترین ربات پایتون برای مدیریت پنل، فروش خودکار و مدیریت پروکسی

## ⚡ نصب خودکار و هوشمند
برای نصب و راه‌اندازی کامل ربات، دستور زیر را در ترمینال سرور خود وارد کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/wirenest/wirenest-panel/master/install.sh)
```

## 🔥 ویژگی‌های کامل و جزئیات
### 🏢 سیستم پنل‌میکر (Panel Maker)
- **ساخت خودکار:** راه‌اندازی ساب‌پنل‌ها و اکانت‌های اختصاصی به صورت خودکار.
- **اتصال به PasarGuard:** ارتباط بومی و امن با APIهای پنل‌های PasarGuard.
- **مدیریت چندنودی:** کنترل چندین سرور و نود مختلف از طریق یک ربات مرکزی.

### 💰 سیستم مالی و فروش
- **کیف پول هوشمند:** شارژ آنی کیف پول توسط کاربران.
- **تایید رسیدها:** سیستم خودکار تایید و بررسی فیش‌های واریزی.
- **تخفیف و هدیه:** مدیریت کدهای تخفیف و کارت‌های هدیه شارژ.

### 🤖 اتوماسیون و تحویل
- **تحویل آنی:** فرآیند خرید سریع و دریافت خودکار کانفیگ‌ها.
- **سرویس تست رایگان:** ارائه اکانت‌های تست محدود با مدیریت خودکار زمان انقضا.

### 🛠 مدیریت و امنیت
- **داشبورد ادمین:** سیستم ارسال پیام همگانی (Broadcast)، آمار زنده و سیستم تیکت پشتیبانی.
- **امنیت:** استفاده از روش‌های پیشرفته رمزنگاری برای حفظ اطلاعات حساس.
- **نگهداری:** کلید برق اضطراری جهت خاموش/روشن کردن ربات برای نگهداری.

## 🛠 مدیریت ربات با CLI
بعد از نصب، از دستورات زیر در ترمینال استفاده کنید:
- `wirenest-panel update` — دریافت آخرین آپدیت از گیت‌هاب
- `wirenest-panel status` — مشاهده وضعیت اجرای ربات
- `wirenest-panel restart` — ری‌استارت کردن ربات

## 📂 ساختار پروژه
- **`pesarguard/`**: هسته اصلی (منطق ربات، دیتابیس، هندلرها).
- **`run.py`**: نقطه شروع اجرای ربات.
- **`requirements.txt`**: کتابخانه‌های مورد نیاز پایتون.
