# 🤖 WireNest | بازارساز پنل پاسارگاد و ربات فروش 🚀

### یک ربات تلگرامی پایتون برای ساخت پنل‌های پاسارگاد، مدیریت سرویس‌های پروکسی و اتوماسیون فروش

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python Version](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://python.org/)
[![Platform](https://img.shields.io/badge/Platform-Debian%20%7C%20Ubuntu-lightgrey.svg)](#-requirements)

[English 🇺🇸](README.md)

پروژه WireNest به شما اجازه می‌دهد پنل‌های پاسارگاد را کاملاً از طریق تلگرام بفروشید و مدیریت کنید. مشتریان پلن‌ها را مشاهده می‌کنند، کیف پول خود را شارژ می‌کنند، سرویس می‌خرند و اطلاعات پنل را بلافاصله دریافت می‌کنند، در حالی که شما همه چیز را از پنل مدیریت داخل ربات کنترل می‌کنید. رابط کاربری ربات کاملاً فارسی است.

## ✅ نیازمندی‌ها

| مورد | نیازمندی |
|---|---|
| سیستم عامل | دبیان 12 به بالا یا اوبونتو 22.04 به بالا (نیاز به `apt` و `systemd`) |
| دسترسی | `root` یا `sudo` |
| پایتون | نسخه 3.10 یا جدیدتر (نصب‌کننده به صورت خودکار این را تنظیم می‌کند) |
| تلگرام | یک توکن ربات از ربات [@BotFather](https://t.me/BotFather) و آیدی عددی تلگرام شما (از [@userinfobot](https://t.me/userinfobot)) |
| پنل | حداقل یک پنل پاسارگاد در دسترس همراه با حساب ادمین |

## ⚡ نصب

این دستور را روی سرور خود اجرا کنید:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/wirenest/wirenest-panel/master/install.sh)"
```

نصب‌کننده از شما **توکن ربات** و **آیدی تلگرام ادمین** را می‌پرسد، توکن را در تلگرام اعتبارسنجی می‌کند و سپس مراحل زیر را انجام می‌دهد:

1. پکیج‌های مورد نیاز را نصب می‌کند (پایتون ۳.۱۰ به بالا، گیت، کرل)،
2. ربات را در مسیر `/opt/wirenest-panel` دانلود می‌کند،
3. یک محیط مجازی (Virtual Environment) ایجاد کرده و وابستگی‌ها را نصب می‌کند،
4. سرویس `systemd` با نام `wirenest` را ثبت و اجرا می‌کند،
5. دستور مدیریتی `wirenest-panel` را نصب می‌کند.

### نصب غیرتعاملی (Non-interactive)

```bash
BOT_TOKEN="123456:ABC-your-token" ADMIN_ID="123456789" sudo -E bash -c "$(curl -fsSL https://raw.githubusercontent.com/wirenest/wirenest-panel/master/install.sh)"
```

> اجرای مجدد نصب‌کننده روی سروری که از قبل WireNest را دارد، کدها را بروزرسانی می‌کند اما **پوشه‌های `data/` و `logs/` شما دست‌نخورده باقی می‌مانند**.

## 🚀 اولین اجرا

1. ربات خود را در تلگرام باز کرده و دستور `/start` را بفرستید. اکانتی که آیدی آن را به نصب‌کننده دادید، دکمه **👨‍💼 پنل مدیریت** را دریافت خواهد کرد.
2. در بخش **📦 مدیریت پنل**، پنل‌های پاسارگاد خود را اضافه کرده و پلن‌های فروش (حجم و قیمت) را بسازید.
3. در بخش **⚙️ تنظیمات**، شماره کارت / نام صاحب حساب، درگاه‌های پرداخت، پشتیبانی و متن‌های ربات را تنظیم کنید.
4. (اختیاری) در بخش **📚 مدیریت راهنما**، آموزش‌های اتصال، قوانین، سوالات متداول و کدهای تخفیف یا هدیه را تعریف کنید.
5. با یک اکانت معمولی دستور `/start` را بفرستید و یک خرید آزمایشی را تست کنید.

## 🔥 ویژگی‌ها

### 👤 برای مشتریان
- **🔐 خرید اشتراک:** انتخاب پلن، مشاهده پیش‌فاکتور و دریافت فوری آدرس پنل، نام کاربری و رمز عبور.
- **🏦 کیف پول و شارژ:** شارژ از طریق کارت‌به‌کارت، تتر، زرین‌پال یا آقای‌پرداخت (به انتخاب ادمین)؛ رسیدها توسط ادمین بررسی می‌شوند.
- **🏷 کدهای تخفیف:** اعمال کد تخفیف در صفحه فاکتور، حتی پیش از اینکه کیف پول موجودی کافی داشته باشد. قیمت تخفیف‌خورده تا مرحله پرداخت نهایی اعمال می‌ماند.
- **🛍 سرویس‌های من:** مشاهده سرویس‌ها، تغییر رمز عبور پنل و خرید حجم اضافه.
- **🧪 سرویس تست رایگان:** اکانت‌های آزمایشی زمان‌دار که پس از انقضا به صورت خودکار حذف می‌شوند.
- **📡 راهنمای اتصال، 📋 قوانین، ❓ سوالات متداول و ☎️ پشتیبانی.**
- **🎁 کدهای هدیه:** فعال‌سازی کدهای هدیه شارژ کیف پول.
- **📢 عضویت اجباری در کانال** (اختیاری).

### 🛠 برای ادمین‌ها
- **📊 آمار:** گزارش فروش و نمای کلی وضعیت سیستم.
- **📦 مدیریت پنل:** اتصال چند پنل/نود پاسارگاد و مدیریت پلن‌های آن‌ها.
- **👥 مدیریت کاربران:** کارت کاربران، موجودی کیف پول و سرویس‌ها.
- **🧾 صف رسیدها:** تایید، رد، یا تایید همراه با اصلاح مبلغ رسیدهای واریزی.
- **🏷 کدهای تخفیف و 🎁 کدهای هدیه:** درصدی یا مبلغ ثابت، محدودیت تعداد استفاده و تاریخ انقضا.
- **🛠 سوئیچ قابلیت‌ها:** فعال یا غیرفعال‌سازی خرید، شارژ، مدیریت سرویس، هدیه، راهنما و سوالات متداول.
- **📣 ارسال پیام همگانی (Broadcast) و 🎫 مدیریت تیکت‌های پشتیبانی.**
- **🎨 ظاهر ربات:** شخصی‌سازی استایل دکمه‌ها و متن‌ها.
- **🔌 کلید قطع و وصل:** روشن یا خاموش کردن کلی ربات برای تعمیرات و نگهداری.

### ⚙️ اتوماسیون و امنیت
- **کارهای پس‌زمینه (Background jobs):** پاکسازی خودکار تست‌های منقضی شده و خریدهای معلق قدیمی.
- **رمزنگاری رمز عبور پنل‌ها:** ذخیره‌سازی به صورت رمزنگاری شده (AES-GCM) و هرگز به صورت متن ساده (Plain text).
- **بررسی رسیدهای پرداختی** برای جلوگیری از تکرار کدهای تراکنش.
- **استفاده ایمن از کدهای تخفیف** (جلوگیری از عبور از سقف مجاز استفاده).
- **حالت پایدار (Persistent state)** برای ادامه فرآیند کاربران پس از ریستارت ربات.

## 🛠 مدیریت با CLI

پس از نصب، از این دستورات (با دسترسی root) استفاده کنید:

| دستور | توضیحات |
|---|---|
| `wirenest-panel status` | نمایش وضعیت سرویس ربات |
| `wirenest-panel logs [lines]` | نمایش خطوط آخر لاگ (پیش‌فرض ۱۰۰ خط) |
| `wirenest-panel restart` | ریستارت کردن ربات |
| `wirenest-panel update` | دریافت آخرین نسخه از گیت‌هاب، نصب مجدد وابستگی‌ها و ریستارت ربات |
| `wirenest-panel uninstall` | حذف کامل ربات **و اطلاعات آن** (همراه با درخواست تایید) |

## 🧰 نصب دستی (پیشرفته)

```bash
git clone https://github.com/wirenest/wirenest-panel.git
cd wirenest-panel
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

فایل `pesarguard/config.py` را ویرایش کرده و مقادیر زیر را وارد کنید:

```python
BOT_TOKEN = "123456:ABC-your-token"
ADMIN_ID = 123456789
```

سپس ربات را اجرا کنید:

```bash
./venv/bin/python run.py
```

اطلاعات و دیتابیس در کنار فایل `run.py` ذخیره می‌شوند: `data/bot.sqlite` (دیتابیس)، `data/state.json` و `logs/bot.log`.

## 🔄 بروزرسانی و بکاپ

- **بروزرسانی:** دستور `sudo wirenest-panel update`. این دستور کدها را به آخرین نسخه گیت‌هاب آپدیت می‌کند، بنابراین **فایل‌های داخل `/opt/wirenest-panel` را دستی ویرایش نکنید** (توکن و آیدی ادمین شما به صورت خودکار از `/etc/wirenest-panel/bot.env` اعمال می‌شوند).
- **بکاپ‌گیری:** پوشه `data/` (و به صورت اختیاری `logs/`) را کپی کنید:

  ```bash
  sudo cp -a /opt/wirenest-panel/data /root/wirenest-data-backup
  ```

- **بازیابی (Restore):** سرویس را متوقف کنید، پوشه بکاپ را در مسیر `/opt/wirenest-panel/data` قرار دهید و سپس سرویس را مجدداً استارت کنید.

## 📂 ساختار پروژه

```text
wirenest-panel/
├── run.py                    # نقطه ورود (Entry point)
├── install.sh                # نصب‌کننده خودکار
├── requirements.txt          # کتابخانه‌های پایتون
└── pesarguard/               # هسته ربات
    ├── config.py             # توکن، آیدی ادمین، مسیرها
    ├── bootstrap.py          # منطقه زمانی، پوشه‌ها، لاگینگ
    ├── database.py           # توابع کمکی SQLite و تنظیمات
    ├── state.py              # وضعیت مکالمه کاربران
    ├── telegram_api.py       # توابع ارسال/ویرایش پیام تلگرام
    ├── panel_api.py          # کلاینت API پنل پاسارگاد
    ├── crypto.py             # رمزنگاری رمز عبور
    ├── keyboards.py          # منوها و کیبوردهای شیشه‌ای
    ├── dispatcher.py         # هدایت آپدیت‌ها به هندلرها
    ├── cron.py               # کارهای پس‌زمینه (Background jobs)
    ├── main.py               # راه‌اندازی اپلیکیشن
    └── handlers/
        ├── user/             # خرید، کیف پول، سرویس‌ها، تست، رسیدها، اطلاعات
        └── admin/            # آمار، پنل‌ها، کاربران، رسیدها، تخفیف‌ها، ارسال همگانی، ...
```

## 🩺 عیب‌یابی

| مشکل | راه حل |
|---|---|
| ربات پاسخ نمی‌دهد | دستور `sudo wirenest-panel status` و سپس `sudo wirenest-panel logs 200` را بررسی کنید |
| نصب‌کننده می‌گوید نسخه پایتون قدیمی است | از اوبونتو 22.04+ یا دبیان 12+ استفاده کنید |
| لاگ‌ها می‌گویند توکن ربات خالی است (`BOT_TOKEN خالیه`) | دستور `sudo wirenest-panel update` را اجرا کنید تا توکن از `/etc/wirenest-panel/bot.env` اعمال شود |
| امکان ساخت سرویس وجود ندارد | آدرس پنل، اطلاعات ادمین و اتصال سرور به پنل را بررسی کنید |
| تلگرام از روی سرور در دسترس نیست | مطمئن شوید سرور می‌تواند به `api.telegram.org` متصل شود |

## 🔐 نکات امنیتی

- توکن در فایل‌های `/etc/wirenest-panel/bot.env` و `pesarguard/config.py` ذخیره می‌شود که فقط توسط کاربر root قابل خواندن هستند.
- فقط آیدی تلگرامی که به عنوان ادمین ثبت شده (`ADMIN_ID`) می‌تواند پنل مدیریت را باز کند.
