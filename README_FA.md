## ⚡ نصب سریع و خودکار روی سرور

برای نصب و راه‌اندازی خودکار این ربات قدرتمند روی سرور خود، دستور زیر را با دسترسی روت (`sudo`) اجرا کنید:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/wirenest/wirenest-panel/master/install.sh)"
```

در حین نصب، اسکریپت به صورت تعاملی موارد زیر را دریافت می‌کند:
1. 🔑 **توکن ربات تلگرام** (`Bot Token`)
2. 👤 **آیدی عددی ادمین** (`Admin Telegram ID`)
