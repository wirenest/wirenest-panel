## 🚀 نصب سریع و خودکار

برای نصب خودکار ربات روی سرور خود، دستور زیر را اجرا کنید:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/wirenest/wirenest-panel/master/install.sh)"
```

در جریان نصب، اسکریپت به صورت خودکار موارد زیر را از شما دریافت می‌کند:
۱. **توکن ربات تلگرام (Bot Token)**
۲. **آیدی عددی ادمین (Admin Telegram ID)**

## ✨ لیست کامل ویژگی‌ها و امکانات

- **سازگار با هاست اشتراکی و cPanel:** بهینه شده برای اجرا روی سرورهای لینوکسی بدون نیاز به پروس스‌های دائمی پس‌زمینه.
- **پشتیبانی از چند پنل و چند نود:** قابلیت اتصال، مدیریت و تست اتصال همزمان به چندین پنل پاسارگاد، مرزبان و سنایی.
- **امنیت پیشرفته و رمزنگاری:** استفاده از سیستم رمزنگاری قدرتمند `AES-256-GCM` جهت ذخیره‌سازی امن اطلاعات توکن‌ها و پسوردها.
- **عبور از کلودفلر (WAF Bypass):** پشتیبانی ترکیبی از cURL خالص PHP و پل پایتون (`panel_bridge.py`) برای عبور از فایروال پنل‌ها.
- **جریان کامل فروش و مالی:**
  - تحویل آنی اشتراک و مدیریت سرویس‌ها.
  - سیستم کیف پول کامل با قابلیت افزایش اعتبار و کسر موجودی.
  - آپلود و تایید خودکار رسیدهای واریز وجه توسط ادمین.
  - مدیریت کدهای تخفیف و کدهای هدیه (Gift/Discount codes).
- **ابزارهای پیشرفته مدیریت:**
  - سیستم ارسال پیام همگانی (Broadcast) پیشرفته (ارسال به همه، خریداران، افراد بدون خرید).
  - آمار دقیق، جستجوی کاربران و تغییر موجودی گروهی.
  - مدیریت تیکت‌ها و ارتباط با پشتیبانی.
  - کلید روشن/خاموش کردن ربات (Power switch).

## 📂 ساختار پروژه

- پوشه `core/` — راه‌اندازی ربات، روترها، وبهوک و کرون‌جاب.
- پوشه `admin/` — پنل‌های مدیریت، ارسال همگانی، آمار و تنظیمات.
- پوشه `flows/` — جریان‌های خرید کاربر، کیف پول و مدیریت سرویس‌ها.
- پوشه `lib/` — کلاینت‌های API پنل، توابع رمزنگاری و پل پایتون.
