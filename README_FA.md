# 🤖 ربات هوشمند WireNest | مدیریت پنل PasarGuard 🚀
### پیشرفته‌ترین ربات پایتون برای مدیریت پنل، فروش خودکار و مدیریت پروکسی

## ⚡ نصب خودکار و هوشمند
برای نصب و راه‌اندازی کامل ربات، دستور زیر را در ترمینال سرور خود وارد کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/wirenest/wirenest-panel/master/install.sh)
```

## 🔥 ویژگی‌های کلیدی
- 🏢 **Panel Maker:** مدیریت و ساخت خودکار پنل‌های اختصاصی و اکانت‌ها.
- 🔗 **PasarGuard:** ارتباط مستقیم و بدون واسطه با APIهای پنل‌های PasarGuard.
- 💰 **سیستم مالی:** کیف پول هوشمند، تایید خودکار رسیدها و سیستم تخفیف.
- 🧪 **سرویس تست رایگان:** ارائه اکانت تست با قابلیت انقضای خودکار.
- 📢 **داشبورد ادمین:** سیستم ارسال پیام همگانی (Broadcast)، آمار زنده و تیکت پشتیبانی.
- 🛡 **امنیت:** استفاده از روش‌های رمزنگاری پیشرفته برای حفظ اطلاعات حساس.

## 🛠 مدیریت ربات با CLI
بعد از نصب، از دستورات زیر در ترمینال برای مدیریت استفاده کنید:
- `wirenest-panel update` — دریافت آخرین آپدیت از گیت‌هاب
- `wirenest-panel status` — مشاهده وضعیت اجرای ربات
- `wirenest-panel restart` — ری‌استارت کردن ربات

## 📂 ساختار پروژه
- **`pesarguard/`**: هسته اصلی (منطق ربات، دیتابیس، هندلرها).
- **`run.py`**: نقطه شروع اجرای ربات.
- **`requirements.txt`**: کتابخانه‌های مورد نیاز پایتون.
